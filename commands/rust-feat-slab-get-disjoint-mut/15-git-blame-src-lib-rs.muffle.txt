14	//! Pre-allocated storage for a uniform data type.
15	//!
16	//! `Slab` provides pre-allocated storage for a single data type. If many values
17	//! of a single type are being allocated, it can be more efficient to
18	//! pre-allocate the necessary storage. Since the size of the type is uniform,
19	//! memory fragmentation can be avoided. Storing, clearing, and lookup
20	//! operations become very cheap.
21	//!
22	//! While `Slab` may look like other Rust collections, it is not intended to be
23	//! used as a general purpose collection. The primary difference between `Slab`
24	//! and `Vec` is that `Slab` returns the key when storing the value.
25	//!
26	//! It is important to note that keys may be reused. In other words, once a
27	//! value associated with a given key is removed from a slab, that key may be
28	//! returned from future calls to `insert`.
29	//!
30	//! # Examples
31	//!
32	//! Basic storing and retrieval.
33	//!
34	//! ```
35	//! # use slab::*;
36	//! let mut slab = Slab::new();
37	//!
38	//! let hello = slab.insert("hello");
39	//! let world = slab.insert("world");
40	//!
41	//! assert_eq!(slab[hello], "hello");
42	//! assert_eq!(slab[world], "world");
43	//!
44	//! slab[world] = "earth";
45	//! assert_eq!(slab[world], "earth");
46	//! ```
47	//!
48	//! Sometimes it is useful to be able to associate the key with the value being
49	//! inserted in the slab. This can be done with the `vacant_entry` API as such:
50	//!
51	//! ```
52	//! # use slab::*;
53	//! let mut slab = Slab::new();
54	//!
55	//! let hello = {
56	//!     let entry = slab.vacant_entry();
57	//!     let key = entry.key();
58	//!
59	//!     entry.insert((key, "hello"));
60	//!     key
61	//! };
62	//!
63	//! assert_eq!(hello, slab[hello].0);
64	//! assert_eq!("hello", slab[hello].1);
65	//! ```
66	//!
67	//! It is generally a good idea to specify the desired capacity of a slab at
68	//! creation time. Note that `Slab` will grow the internal capacity when
69	//! attempting to insert a new value once the existing capacity has been reached.
70	//! To avoid this, add a check.
71	//!
72	//! ```
73	//! # use slab::*;
74	//! let mut slab = Slab::with_capacity(1024);
75	//!
76	//! // ... use the slab
77	//!
78	//! if slab.len() == slab.capacity() {
79	//!     panic!("slab full");
80	//! }
81	//!
82	//! slab.insert("the slab is not at capacity yet");
83	//! ```
84	//!
85	//! # Capacity and reallocation
86	//!
87	//! The capacity of a slab is the amount of space allocated for any future
88	//! values that will be inserted in the slab. This is not to be confused with
89	//! the *length* of the slab, which specifies the number of actual values
90	//! currently being inserted. If a slab's length is equal to its capacity, the
91	//! next value inserted into the slab will require growing the slab by
92	//! reallocating.
93	//!
94	//! For example, a slab with capacity 10 and length 0 would be an empty slab
95	//! with space for 10 more stored values. Storing 10 or fewer elements into the
96	//! slab will not change its capacity or cause reallocation to occur. However,
97	//! if the slab length is increased to 11 (due to another `insert`), it will
98	//! have to reallocate, which can be slow. For this reason, it is recommended to
99	//! use [`Slab::with_capacity`] whenever possible to specify how many values the
100	//! slab is expected to store.
101	//!
102	//! # Implementation
103	//!
104	//! `Slab` is backed by a `Vec` of slots. Each slot is either occupied or
105	//! vacant. `Slab` maintains a stack of vacant slots using a linked list. To
106	//! find a vacant slot, the stack is popped. When a slot is released, it is
107	//! pushed onto the stack.
108	//!
109	//! If there are no more available slots in the stack, then `Vec::reserve(1)` is
110	//! called and a new slot is created.
111	//!
112	//! [`Slab::with_capacity`]: struct.Slab.html#with_capacity

307	    /// Reserve capacity for at least `additional` more values to be stored
308	    /// without allocating.
309	    ///
310	    /// `reserve` does nothing if the slab already has sufficient capacity for
311	    /// `additional` more values. If more capacity is required, a new segment of
312	    /// memory will be allocated and all existing values will be copied into it.
313	    /// As such, if the slab is already very large, a call to `reserve` can end
314	    /// up being expensive.
315	    ///
316	    /// The slab may reserve more than `additional` extra space in order to
317	    /// avoid frequent reallocations. Use `reserve_exact` instead to guarantee
318	    /// that only the requested space is allocated.
319	    ///
320	    /// # Panics
321	    ///
322	    /// Panics if the new capacity exceeds `isize::MAX` bytes.
323	    ///
324	    /// # Examples
325	    ///
326	    /// ```
327	    /// # use slab::*;
328	    /// let mut slab = Slab::new();
329	    /// slab.insert("hello");
330	    /// slab.reserve(10);
331	    /// assert!(slab.capacity() >= 11);
332	    /// ```
333	    pub fn reserve(&mut self, additional: usize) {
334	        if self.capacity() - self.len >= additional {
335	            return;
336	        }
337	        let need_add = additional - (self.entries.len() - self.len);
338	        self.entries.reserve(need_add);
339	    }

341	    /// Reserve the minimum capacity required to store exactly `additional`
342	    /// more values.
343	    ///
344	    /// `reserve_exact` does nothing if the slab already has sufficient capacity
345	    /// for `additional` more values. If more capacity is required, a new segment
346	    /// of memory will be allocated and all existing values will be copied into
347	    /// it.  As such, if the slab is already very large, a call to `reserve` can
348	    /// end up being expensive.
349	    ///
350	    /// Note that the allocator may give the slab more space than it requests.
351	    /// Therefore capacity can not be relied upon to be precisely minimal.
352	    /// Prefer `reserve` if future insertions are expected.
353	    ///
354	    /// # Panics
355	    ///
356	    /// Panics if the new capacity exceeds `isize::MAX` bytes.
357	    ///
358	    /// # Examples
359	    ///
360	    /// ```
361	    /// # use slab::*;
362	    /// let mut slab = Slab::new();
363	    /// slab.insert("hello");
364	    /// slab.reserve_exact(10);
365	    /// assert!(slab.capacity() >= 11);
366	    /// ```
367	    pub fn reserve_exact(&mut self, additional: usize) {
368	        if self.capacity() - self.len >= additional {
369	            return;
370	        }
371	        let need_add = additional - (self.entries.len() - self.len);
372	        self.entries.reserve_exact(need_add);
373	    }

375	    /// Shrink the capacity of the slab as much as possible without invalidating keys.
376	    ///
377	    /// Because values cannot be moved to a different index, the slab cannot
378	    /// shrink past any stored values.
379	    /// It will drop down as close as possible to the length but the allocator may
380	    /// still inform the underlying vector that there is space for a few more elements.
381	    ///
382	    /// This function can take O(n) time even when the capacity cannot be reduced
383	    /// or the allocation is shrunk in place. Repeated calls run in O(1) though.
384	    ///
385	    /// # Examples
386	    ///
387	    /// ```
388	    /// # use slab::*;
389	    /// let mut slab = Slab::with_capacity(10);
390	    ///
391	    /// for i in 0..3 {
392	    ///     slab.insert(i);
393	    /// }
394	    ///
395	    /// slab.shrink_to_fit();
396	    /// assert!(slab.capacity() >= 3 && slab.capacity() < 10);
397	    /// ```
398	    ///
399	    /// The slab cannot shrink past the last present value even if previous
400	    /// values are removed:
401	    ///
402	    /// ```
403	    /// # use slab::*;
404	    /// let mut slab = Slab::with_capacity(10);
405	    ///
406	    /// for i in 0..4 {
407	    ///     slab.insert(i);
408	    /// }
409	    ///
410	    /// slab.remove(0);
411	    /// slab.remove(3);
412	    ///
413	    /// slab.shrink_to_fit();
414	    /// assert!(slab.capacity() >= 3 && slab.capacity() < 10);
415	    /// ```
416	    pub fn shrink_to_fit(&mut self) {
417	        // Remove all vacant entries after the last occupied one, so that
418	        // the capacity can be reduced to what is actually needed.
419	        // If the slab is empty the vector can simply be cleared, but that
420	        // optimization would not affect time complexity when T: Drop.
421	        let len_before = self.entries.len();
422	        while let Some(&Entry::Vacant(_)) = self.entries.last() {
423	            self.entries.pop();
424	        }
425	
426	        // Removing entries breaks the list of vacant entries,
427	        // so it must be repaired
428	        if self.entries.len() != len_before {
429	            // Some vacant entries were removed, so the list now likely¹
430	            // either contains references to the removed entries, or has an
431	            // invalid end marker. Fix this by recreating the list.
432	            self.recreate_vacant_list();
433	            // ¹: If the removed entries formed the tail of the list, with the
434	            // most recently popped entry being the head of them, (so that its
435	            // index is now the end marker) the list is still valid.
436	            // Checking for that unlikely scenario of this infrequently called
437	            // is not worth the code complexity.
438	        }
439	
440	        self.entries.shrink_to_fit();
441	    }

443	    /// Iterate through all entries to recreate and repair the vacant list.
444	    /// self.len must be correct and is not modified.
445	    fn recreate_vacant_list(&mut self) {
446	        self.next = self.entries.len();
447	        // We can stop once we've found all vacant entries
448	        let mut remaining_vacant = self.entries.len() - self.len;
449	        if remaining_vacant == 0 {
450	            return;
451	        }
452	
453	        // Iterate in reverse order so that lower keys are at the start of
454	        // the vacant list. This way future shrinks are more likely to be
455	        // able to remove vacant entries.
456	        for (i, entry) in self.entries.iter_mut().enumerate().rev() {
457	            if let Entry::Vacant(ref mut next) = *entry {
458	                *next = self.next;
459	                self.next = i;
460	                remaining_vacant -= 1;
461	                if remaining_vacant == 0 {
462	                    break;
463	                }
464	            }
465	        }
466	    }

468	    /// Reduce the capacity as much as possible, changing the key for elements when necessary.
469	    ///
470	    /// To allow updating references to the elements which must be moved to a new key,
471	    /// this function takes a closure which is called before moving each element.
472	    /// The second and third parameters to the closure are the current key and
473	    /// new key respectively.
474	    /// In case changing the key for one element turns out not to be possible,
475	    /// the move can be cancelled by returning `false` from the closure.
476	    /// In that case no further attempts at relocating elements is made.
477	    /// If the closure unwinds, the slab will be left in a consistent state,
478	    /// but the value that the closure panicked on might be removed.
479	    ///
480	    /// # Examples
481	    ///
482	    /// ```
483	    /// # use slab::*;
484	    ///
485	    /// let mut slab = Slab::with_capacity(10);
486	    /// let a = slab.insert('a');
487	    /// slab.insert('b');
488	    /// slab.insert('c');
489	    /// slab.remove(a);
490	    /// slab.compact(|&mut value, from, to| {
491	    ///     assert_eq!((value, from, to), ('c', 2, 0));
492	    ///     true
493	    /// });
494	    /// assert!(slab.capacity() >= 2 && slab.capacity() < 10);
495	    /// ```
496	    ///
497	    /// The value is not moved when the closure returns `Err`:
498	    ///
499	    /// ```
500	    /// # use slab::*;
501	    ///
502	    /// let mut slab = Slab::with_capacity(100);
503	    /// let a = slab.insert('a');
504	    /// let b = slab.insert('b');
505	    /// slab.remove(a);
506	    /// slab.compact(|&mut value, from, to| false);
507	    /// assert_eq!(slab.iter().next(), Some((b, &'b')));
508	    /// ```
509	    pub fn compact<F>(&mut self, mut rekey: F)
510	    where
511	        F: FnMut(&mut T, usize, usize) -> bool,
512	    {
513	        // If the closure unwinds, we need to restore a valid list of vacant entries
514	        struct CleanupGuard<'a, T> {
515	            slab: &'a mut Slab<T>,
516	            decrement: bool,
517	        }
518	        impl<T> Drop for CleanupGuard<'_, T> {
519	            fn drop(&mut self) {
520	                if self.decrement {
521	                    // Value was popped and not pushed back on
522	                    self.slab.len -= 1;
523	                }
524	                self.slab.recreate_vacant_list();
525	            }
526	        }
527	        let mut guard = CleanupGuard {
528	            slab: self,
529	            decrement: true,
530	        };
531	
532	        let mut occupied_until = 0;
533	        // While there are vacant entries
534	        while guard.slab.entries.len() > guard.slab.len {
535	            // Find a value that needs to be moved,
536	            // by popping entries until we find an occupied one.
537	            // (entries cannot be empty because 0 is not greater than anything)
538	            if let Some(Entry::Occupied(mut value)) = guard.slab.entries.pop() {
539	                // Found one, now find a vacant entry to move it to
540	                while let Some(&Entry::Occupied(_)) = guard.slab.entries.get(occupied_until) {
541	                    occupied_until += 1;
542	                }
543	                // Let the caller try to update references to the key
544	                if !rekey(&mut value, guard.slab.entries.len(), occupied_until) {
545	                    // Changing the key failed, so push the entry back on at its old index.
546	                    guard.slab.entries.push(Entry::Occupied(value));
547	                    guard.decrement = false;
548	                    guard.slab.entries.shrink_to_fit();
549	                    return;
550	                    // Guard drop handles cleanup
551	                }
552	                // Put the value in its new spot
553	                guard.slab.entries[occupied_until] = Entry::Occupied(value);
554	                // ... and mark it as occupied (this is optional)
555	                occupied_until += 1;
556	            }
557	        }
558	        guard.slab.next = guard.slab.len;
559	        guard.slab.entries.shrink_to_fit();
560	        // Normal cleanup is not necessary
561	        mem::forget(guard);
562	    }

729	    /// given keys simultaneously.
730	    ///
731	    /// If any one of the given keys is not associated with a value, then `None`
732	    /// is returned.
733	    ///
734	    /// This function can be used to get two mutable references out of one slab,
735	    /// so that you can manipulate both of them at the same time, eg. swap them.
736	    ///
737	    /// # Panics
738	    ///
739	    /// This function will panic if `key1` and `key2` are the same.
740	    ///
741	    /// # Examples
742	    ///
743	    /// ```
744	    /// # use slab::*;
745	    /// use std::mem;
746	    ///
747	    /// let mut slab = Slab::new();
748	    /// let key1 = slab.insert(1);
749	    /// let key2 = slab.insert(2);
750	    /// let (value1, value2) = slab.get2_mut(key1, key2).unwrap();
751	    /// mem::swap(value1, value2);
752	    /// assert_eq!(slab[key1], 2);
753	    /// assert_eq!(slab[key2], 1);
754	    /// ```
755	    pub fn get2_mut(&mut self, key1: usize, key2: usize) -> Option<(&mut T, &mut T)> {
756	        assert!(key1 != key2);
757	
758	        let (entry1, entry2);
759	
760	        if key1 > key2 {
761	            let (slice1, slice2) = self.entries.split_at_mut(key1);
762	            entry1 = slice2.get_mut(0);
763	            entry2 = slice1.get_mut(key2);
764	        } else {
765	            let (slice1, slice2) = self.entries.split_at_mut(key2);
766	            entry1 = slice1.get_mut(key1);
767	            entry2 = slice2.get_mut(0);
768	        }
769	
770	        match (entry1, entry2) {
771	            (
772	                Some(&mut Entry::Occupied(ref mut val1)),
773	                Some(&mut Entry::Occupied(ref mut val2)),
774	            ) => Some((val1, val2)),
775	            _ => None,
776	        }
777	    }

843	    ///
844	    /// For a safe alternative see [`get2_mut`](Slab::get2_mut).
845	    ///
846	    /// This function should be used with care.
847	    ///
848	    /// # Safety
849	    ///
850	    /// - Both keys must be within bounds.
851	    /// - The condition `key1 != key2` must hold.
852	    ///
853	    /// # Examples
854	    ///
855	    /// ```
856	    /// # use slab::*;
857	    /// use std::mem;
858	    ///

869	        let ptr = self.entries.as_mut_ptr();
870	        let ptr1 = ptr.add(key1);
871	        let ptr2 = ptr.add(key2);
872	        match (&mut *ptr1, &mut *ptr2) {
873	            (&mut Entry::Occupied(ref mut val1), &mut Entry::Occupied(ref mut val2)) => {
874	                (val1, val2)
875	            }
876	            _ => unreachable!(),
877	        }
878	    }

880	    /// Get the key for an element in the slab.
881	    ///
882	    /// The reference must point to an element owned by the slab.
883	    /// Otherwise this function will panic.
884	    /// This is a constant-time operation because the key can be calculated
885	    /// from the reference with pointer arithmetic.
886	    ///
887	    /// # Panics
888	    ///
889	    /// This function will panic if the reference does not point to an element
890	    /// of the slab.
891	    ///
892	    /// # Examples
893	    ///
894	    /// ```
895	    /// # use slab::*;
896	    ///
897	    /// let mut slab = Slab::new();
898	    /// let key = slab.insert(String::from("foo"));
899	    /// let value = &slab[key];
900	    /// assert_eq!(slab.key_of(value), key);
901	    /// ```
902	    ///
903	    /// Values are not compared, so passing a reference to a different location
904	    /// will result in a panic:
905	    ///
906	    /// ```should_panic
907	    /// # use slab::*;
908	    ///
909	    /// let mut slab = Slab::new();
910	    /// let key = slab.insert(0);
911	    /// let bad = &0;
912	    /// slab.key_of(bad); // this will panic
913	    /// unreachable!();
914	    /// ```
915	    #[track_caller]
916	    pub fn key_of(&self, present_element: &T) -> usize {
917	        let element_ptr = present_element as *const T as usize;
918	        let base_ptr = self.entries.as_ptr() as usize;
919	        // Use wrapping subtraction in case the reference is bad
920	        let byte_offset = element_ptr.wrapping_sub(base_ptr);
921	        // The division rounds away any offset of T inside Entry
922	        // The size of Entry<T> is never zero even if T is due to Vacant(usize)
923	        let key = byte_offset / mem::size_of::<Entry<T>>();
924	        // Prevent returning unspecified (but out of bounds) values
925	        if key >= self.entries.len() {
926	            panic!("The reference points to a value outside this slab");
927	        }
928	        // The reference cannot point to a vacant entry, because then it would not be valid
929	        key
930	    }

1012	    fn insert_at(&mut self, key: usize, val: T) {
1013	        self.len += 1;
1014	
1015	        if key == self.entries.len() {
1016	            self.entries.push(Entry::Occupied(val));
1017	            self.next = key + 1;
1018	        } else {
1019	            self.next = match self.entries.get(key) {
1020	                Some(&Entry::Vacant(next)) => next,
1021	                _ => unreachable!(),
1022	            };
1023	            self.entries[key] = Entry::Occupied(val);
1024	        }
1025	    }

1027	    /// Tries to remove the value associated with the given key,
1028	    /// returning the value if the key existed.
1029	    ///
1030	    /// The key is then released and may be associated with future stored
1031	    /// values.
1032	    ///
1033	    /// # Examples
1034	    ///
1035	    /// ```
1036	    /// # use slab::*;
1037	    /// let mut slab = Slab::new();
1038	    ///
1039	    /// let hello = slab.insert("hello");
1040	    ///
1041	    /// assert_eq!(slab.try_remove(hello), Some("hello"));
1042	    /// assert!(!slab.contains(hello));
1043	    /// ```
1044	    pub fn try_remove(&mut self, key: usize) -> Option<T> {
1045	        if let Some(entry) = self.entries.get_mut(key) {
1046	            // Swap the entry at the provided value
1047	            let prev = mem::replace(entry, Entry::Vacant(self.next));
1048	
1049	            match prev {
1050	                Entry::Occupied(val) => {
1051	                    self.len -= 1;
1052	                    self.next = key;
1053	                    return val.into();
1054	                }
1055	                _ => {
1056	                    // Woops, the entry is actually vacant, restore the state
1057	                    *entry = prev;
1058	                }
1059	            }
1060	        }
1061	        None
1062	    }

1109	    ///
1110	    /// In other words, remove all elements `e` such that `f(usize, &mut e)`
1111	    /// returns false. This method operates in place and preserves the key
1112	    /// associated with the retained values.
1113	    ///
1114	    /// # Examples
1115	    ///

1238	/// Create a slab from an iterator of key-value pairs.
1239	///
1240	/// If the iterator produces duplicate keys, the previous value is replaced with the later one.
1241	/// The keys does not need to be sorted beforehand, and this function always
1242	/// takes O(n) time.
1243	/// Note that the returned slab will use space proportional to the largest key,
1244	/// so don't use `Slab` with untrusted keys.
1245	///
1246	/// # Examples
1247	///
1248	/// ```
1249	/// # use slab::*;
1250	///
1251	/// let vec = vec![(2,'a'), (6,'b'), (7,'c')];
1252	/// let slab = vec.into_iter().collect::<Slab<char>>();
1253	/// assert_eq!(slab.len(), 3);
1254	/// assert!(slab.capacity() >= 8);
1255	/// assert_eq!(slab[2], 'a');
1256	/// ```
1257	///
1258	/// With duplicate and unsorted keys:
1259	///
1260	/// ```
1261	/// # use slab::*;
1262	///
1263	/// let vec = vec![(20,'a'), (10,'b'), (11,'c'), (10,'d')];
1264	/// let slab = vec.into_iter().collect::<Slab<char>>();
1265	/// assert_eq!(slab.len(), 3);
1266	/// assert_eq!(slab[10], 'd');
1267	/// ```
1268	impl<T> FromIterator<(usize, T)> for Slab<T> {
1269	    fn from_iter<I>(iterable: I) -> Self
1270	    where
1271	        I: IntoIterator<Item = (usize, T)>,
1272	    {
1273	        let iterator = iterable.into_iter();
1274	        let mut builder = builder::Builder::with_capacity(iterator.size_hint().0);
1275	
1276	        for (key, value) in iterator {
1277	            builder.pair(key, value)
1278	        }
1279	        builder.build()
1280	    }
1281	}
